Privacy Policy

Last updated: 13 June 2026 · English translation; the Russian version prevails in case of discrepancies.

1. Who we are

Splitaway is an app for tracking shared travel expenses. It is developed as a personal project (rafaelbabaew@googlemail.com). The app runs as a progressive web app (PWA) and as an Android app.

2. What data we collect

Splitaway only collects data that you enter yourself:

  • Trip data — name, destination, list of participants (names, not linked to real identities).
  • Financial records — expense amounts and how they are split. We do not process real payments.
  • Member photo (optional) — if you add a photo yourself in Settings, it is reduced on your phone to about 160×160 pixels and stored with your trip member record. Everyone in that trip can see it. You can remove it at any time; the trip admin can remove it too. It is deleted together with the trip.
  • Install identifier — a random code the app creates itself to link your name in a trip to this device. It is not a hardware device ID or an advertising identifier. It is stored with the trip member record and removed when the name is released or the trip is deleted.
  • Push subscriptions — notification endpoint and keys used to send alerts (only with your explicit consent).

We do not collect: user names, email, phone number, geolocation, hardware device IDs, advertising identifiers, or tracking cookies.

3. How we store data

  • Locally — data is stored in your browser's localStorage.
  • In the cloud — when syncing, data is sent to Supabase (PostgreSQL). Access is protected by invitation tokens and Row Level Security.
  • Hosting — static files are hosted on Netlify (USA). Supabase data is stored in the EU West region.

4. Shared access to a trip

A trip is only accessible to people who have the invitation link with its unique token. Data is not public. The trip organiser can delete all data at any time in the settings.

5. Third-party services

  • Supabase — database and realtime (policy).
  • Netlify — hosting (policy).
  • Anthropic Claude — receipt OCR via an API proxy on Netlify Functions (policy). Receipt images are not stored.

6. Deleting data

To delete all trip data: open the app → Settings → “Delete trip”. This irreversibly deletes all records from the database. Data in localStorage is cleared via “Browser settings → Clear site data”.

7. Children

The app is not intended for children under 13 and does not knowingly collect data about them.

8. Changes

If the policy changes significantly, we will update the date at the top. The current version is always available at splitaway.netlify.app/privacy.html.
