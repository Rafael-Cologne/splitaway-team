# Splitaway — один выпуск для APK и веба

Номер сборки один для обоих: файл `public/version.json` и подпись внизу Настроек «Splitaway 1.0.25 (43)».

1. Claude собирает выпуск: обновляет папку `public` (её же кладёт в APK) и APK в `artifacts`.
2. Вы ставите APK на Android и запускаете `deploy_web.bat` (веб на Netlify из той же папки `public`).
3. Проверка: в Настройках внизу на обоих телефонах одинаковый номер, например «(43)».

Отличия платформ (в одном и том же коде):
- Сканер чека: APK — Google ML Kit на телефоне; веб — Tesseract в браузере (папка `public/vendor/tesseract`, в APK не кладётся). Оба бесплатно и без сервера.
